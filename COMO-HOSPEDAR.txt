COMO COLOCAR O VACABOX ONLINE DE GRAÇA (ranking, leilão e trocas com pessoas reais)
===================================================================================
Resumo: o jogo precisa de um "servidor" Node (o arquivo server.js, já pronto). A opção gratuita mais
simples hoje é o Render. Os planos gratuitos mudam com frequência: confira as regras no site antes.

O QUE VOCÊ VAI PRECISAR (tudo grátis): conta no GitHub e conta no Render. (Opcional: Upstash e UptimeRobot.)

PASSO A PASSO COM O RENDER (render.com)
 1) GitHub: crie uma conta em github.com e um repositório novo (pode ser público ou privado).
    Descompacte o VacaBox-v8.zip e envie TODOS os arquivos para a raiz do repositório
    (botão "Add file" → "Upload files"). O server.js e o index.html têm que ficar na raiz.
 2) Render: entre em render.com com a conta do GitHub.
 3) Clique em "New +" → "Web Service" → escolha o repositório do VacaBox.
 4) Preencha:  Runtime/Language: Node   ·   Build Command: npm install   ·   Start Command: node server.js
    Instance Type: Free.   Clique em "Create Web Service".
 5) Espere o deploy terminar. O Render mostra o endereço, algo como  https://vacabox.onrender.com
 6) Abra o endereço. No jogo, vá em Mais → Perfil: deve aparecer "🌐 online". Mande esse link para os amigos.
    No celular: Chrome → menu ⋮ → "Instalar app"  (iPhone: Safari → Compartilhar → "Adicionar à Tela de Início").

LIMITES DO PLANO GRÁTIS (e como contornar)
 - O servidor "dorme" depois de ~15 minutos sem ninguém acessando e demora cerca de 30 a 60 segundos para
   acordar no primeiro acesso. Para mantê-lo acordado: crie uma conta grátis no UptimeRobot e monitore
   o endereço  https://SEU-APP.onrender.com/api/ping  a cada 5 minutos.
 - O plano grátis tem cerca de 750 horas por mês: um único serviço ligado o mês todo cabe nisso.
 - O disco do plano grátis NÃO é permanente: quando o servidor reinicia, o data.json (ranking, ofertas de troca)
   pode ser apagado. Para guardar os dados, use um Redis gratuito do Upstash:
     a) Crie conta em upstash.com → "Create Database" (Redis) → copie "REST URL" e "REST TOKEN".
     b) No Render: seu serviço → Environment → adicione as variáveis
        UPSTASH_REDIS_REST_URL  e  UPSTASH_REDIS_REST_TOKEN  com esses valores → salve (ele reinicia).
     O servidor passa a salvar e recarregar o ranking e as trocas sozinho.
 - As moedas e vacas de cada jogador ficam salvas no próprio aparelho dele (não no servidor).

OUTRAS OPÇÕES
 - Oracle Cloud "Always Free": uma máquina virtual que fica ligada o tempo todo (pede cartão para verificar
   a conta e é mais trabalhosa: você instala o Node e roda  node server.js).
 - Railway: dá um crédito mensal pequeno; pode acabar se o jogo ficar ligado 24h.
 - Glitch e Heroku não têm mais plano gratuito para isso.

TESTAR NO PRÓPRIO COMPUTADOR
 Instale o Node (nodejs.org), abra um terminal na pasta do jogo e rode:  node server.js
 Depois abra  http://localhost:3000  no navegador.

VARIÁVEIS OPCIONAIS DO SERVIDOR
 PORT (porta), HOUSE_BOT=0 (desliga o bot "Casa 🤖" do leilão), UPSTASH_REDIS_REST_URL / UPSTASH_REDIS_REST_TOKEN.
